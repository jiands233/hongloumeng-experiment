# 三、特别建立“反证”

这是非常重要的一部分。

不要只寻找支持某个结局的材料。

如果不同证据可能指向互相冲突的未来，也必须记录。

例如：

F-XXXX 支持命运 A

F-YYYY 支持命运 B

则建立：

CONFLICT-XXXX

并说明：

- 两组证据
- 为什么冲突
- 是否可以同时成立
- 哪种解释目前证据更强
- 是否必须留到 Phase 3 再判断

**禁止为了形成一个漂亮故事而提前消除歧义。**
